CHANGE REPORT — Premiere Render App — Remote V3 cleanup round

SUMMARY
The latest Remote V3 handoff was uploaded to `feature/v3-supabase-remote`. This cleanup pass removes contradictory Remote V3 documentation and removes legacy LAN controls from the normal Settings UI.

CLEANUP CHANGES
1. `README.md` now describes Supabase-based remote operation as the primary architecture.
2. `AI_DEVELOPER_GUIDE.md` now states the Remote V3 rules and explicitly labels the old LAN implementation as migration/reference only.
3. `docs/ARCHITECTURE.md` now documents Sender -> Supabase -> Render Station.
4. `docs/PROTOCOL.md` now documents the Remote V3 control/file planes and labels the old TCP/UDP protocol as legacy.
5. `docs/SETUP_WINDOWS.md` now describes remote setup without IP entry or port forwarding.
6. `src/ui/main_window.py` status messaging no longer claims that both PCs must be on the same network.
7. `src/ui/settings_panel.py` no longer exposes pairing-code/LAN controls in the normal Settings UI.
8. `docs/REMOTE_V3_CLEANUP.md` records the migration rules and remaining verification work.

AUTHENTICATION
The intended user-facing authentication is username + password only. The current Supabase implementation internally maps usernames to synthetic email identities; the synthetic email is not shown to users.

REMOTE UX INVARIANTS
- Sender and Render Station may be on different networks/locations.
- No normal-use IP entry.
- No normal-use port entry.
- No pairing code.
- No Go Online / Go Offline buttons in the final product.
- Render Station is online while FileSender is open and offline after it closes.
- Send is disabled when the selected Render Station is offline.
- The same Premiere project can be submitted repeatedly as separate jobs.

LEGACY CODE
`src/network/` and related legacy configuration remain temporarily for migration/reference. They are not the Remote V3 transport and must not be extended as the primary architecture. Before final release, isolate or remove the legacy path from the normal UI.

TEST STATUS
The previous AI handoff reported 99 automated tests passing. This cleanup pass was documentation/UI synchronization only and does not constitute live testing.
