CHANGE REPORT — Premiere Render App — REMOTE V3 (gap-closing round)

SUMMARY
This round closes four specific gaps identified in the previous Remote V3 milestone:

1. Friendly user-facing errors: raw backend exceptions are no longer the intended UI message source when a curated message exists.
2. Manual job approval: the Render Station now has a visible pending-jobs banner with Accept/Reject actions when automatic acceptance is disabled.
3. First-run setup: one guided wizard now handles sign-in, role choice (Sender / Render Station / Both), and Render Station basics.
4. Large-file transfer: cloud file upload/download is chunked and resumable so multi-gigabyte Premiere media can recover after interruption.
