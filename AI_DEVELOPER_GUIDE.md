# AI Developer Guide

Read this before modifying the project.

Continue from this architecture.

Do not redesign the project unless required.

Build order:

1. Make the application runnable.
2. Connect UI to modules.
3. Implement direct PC-to-PC networking.
4. Implement large Premiere project transfer.
5. Implement Media Encoder automation.
6. Implement MP4 return transfer.
7. Package Windows installer.

The final app should remain:

Sender + Render Station = Same application.

The app should only operate while open.
